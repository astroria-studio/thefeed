# TheFeed

A modern content platform for indie creators. Built with Astro, deployed on Cloudflare.

## Features

- 7 content formats (article, video, audio, quote, gallery, etc.)
- Stream for quick posts and links
- Daily jokes section
- Full-text search
- Telegram bot publishing
- AI-assisted content production

## Quick Start

```bash
# 1. Configure
cp thefeed.config.example.ts thefeed.config.ts
# Edit thefeed.config.ts with your settings

# 2. Install
cd app && npm install

# 3. Develop
npm run dev
```
